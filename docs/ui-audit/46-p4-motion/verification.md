主实现 `ccc21c0`，补充修复 `5ff9bbd`、`0fd31a8`、`7b70ad5`；最终随包源码 `7b70ad5`，分支 `feat/0.6-native-workbench`。用户明确要求开始 P4 后，在上一批验证切片上扩展。**约定场景已实现，严格性能与人工验收未全部通过，不能标记 P4 全部验收完成。** 没有开始 P5–P10，没有 push。

## 实现

- 任务库与工作台：侧栏按固定内容宽度裁剪开合，内容整体 8 px / 淡入，300 ms；返回任务库先完成既有同步读取，再启动动画，避免读取耗尽整段动画时间。
- 译前准备 → 段落网格：250 ms 整体进入，正文按终态布局，不逐字、逐项动画。
- PDF 原页：定位与渲染延后到开合结束，只渲染最新选择；换任务立即失效旧结果，避免旧页面回写。280 ms 容器开合，与检查与修复共享一个列过渡，交叉开合也以最后一次操作为准；RTL 镜像。过渡结束后恢复用户可拖动的自由宽度。
- 浮窗：从锚点展开 200 ms、收回 150 ms；中途隐藏内容，避免正文缩放或逐帧换行；Esc、关闭按钮及原生外部点击继续关闭。取消旧过渡不会执行旧的关闭回调。
- 进度：250 ms 向真实值插值，显示值永远不超过真实值；减少、阶段或量程切换直接落到真实值；运行色调平滑变化。检查状态变更给出一次轻微缩放反馈。
- 保存：只有后台落盘成功才显示行内 ✓，该行底色用主题色淡出 400 ms；不改编辑器内容、光标和撤销栈，失败不播放成功反馈。
- 导入、启动翻译：按钮内等待并禁用重复触发；启动前的读取和配置持久化也移到 worker。导入超过 3 秒才显示非模态进度窗口，仍可在后台运行；结束或失败恢复按钮。所有等待条共用尊重减少动态效果的进度组件。
- 检查面板首显的译名修复预览推迟到过渡结束，不在展开帧里扫描全文；取消、隐藏、resize、拖动分隔条均可完成清理。
- 列宽变化后分批重算自然行高时，保留可见编辑行的滚动锚点，不把正在编辑的行挤出视口。连续保存同一段只在最新排队文本落盘后显示成功反馈。
- 修复导航复测发现的实际问题：从任务库重开同样行数的任务，Qt 不发选择信号时也恢复编辑器与检查器。
- 统一复用应用偏好、环境及 macOS 系统的减少动态效果规则；快速重复操作直接落到最新终态。正文、检查器文本、列表项、撤销和悬停没有单独动画。面板和浮窗保持不透明，没有新增半透明窗口或叠层。新增等待文案追加到全部 5 个 Qt locale。

## 测量修正与结果

上一批 DMG 流程中“审校心跳最大 555.6 ms”的原始记录保留，但不能直接解释为客户端冻结。`selftest.Flow.pump(interval=.5)` 每轮休眠 0.5 秒，审校就绪循环也直接休眠 0.5 秒，期间没有处理 Qt 事件。本批保留低频状态查询，同时每 10 ms 处理事件，去掉审校循环中的同类休眠，并用心跳回归验证。修正后的源码 DOCX / PDF 主流程通过，50 ms 心跳最大间隔 77.0 ms，见 `source-flow.json`。

Cocoa 真实窗口，3856 段任务的隔离副本，数据、日志、QSettings 均隔离；使用 Qt 焦点查询和 `QWidget.grab()`，未使用 AX 自动化。可复现脚本：`docs/qt-beta/acceptance-feedback-2026-10-14-tools/p4_motion_slice.py`。

| 切换耗时（扣除探针固定 30 ms 事件处理） | 中位数 3.36 ms，最大 4.53 ms |

导航心跳在同步调用结束后重新计时，单列调用耗时，没有把约半秒的读取从结果中省略。cProfile 显示：返回任务库主要花在列表摘要读取的两次完整状态隔离复制；打开任务主要花在交付预检、审校列表和段落详情更新。分别见 `navigation-home-profile.txt`、`navigation-open-profile.txt`。这些根因仍未改成异步或增量读取，本批不能宣称“导航没有冻结”。

保留 `metrics-initial-full.json` 与 `metrics-before-popup-focus.json`，没有把历次波动改写为最后一次结果。一次浮窗探针在窗口未激活时自动隐藏；补上打开前的显式窗口激活后终态通过，符合 Qt.Popup 失去激活即关闭的行为。没有改产品的外部点击关闭规则。
