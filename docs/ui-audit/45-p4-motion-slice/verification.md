# P4 动效验证切片（2026-10-15）

范围：验收反馈 P4 / 动效审计第 3 节的「段落切换 + 检查与修复侧栏」。当前实现尚未通过全部验收，不能据此宣布 P4 或 0.6 完成。

## 已实施

- `motion.Motion`：局部 key 管理动画；中断时停止旧动画，快速输入直接到达最新终态，没有动画队列或过期完成回调。240 ms / InOutCubic 用于侧栏。
- 减少动态效果：应用显式偏好 `appearance/reduce_motion` > `FOLITH_REDUCE_MOTION` > 非交互 / offscreen > macOS NSWorkspace；系统值有 5 秒缓存。保留显式环境覆盖供真实窗口探针使用；应用内开关的界面留到 P5。
- P3b 已让普通行全部展开，所以保留自然行高，选择审计允许的「只锚定滚动、不插值行高」。目标原本可见时，旧行恢复与新编辑框加载之后补偿像素滚动；目标在屏幕外时仍正常滚动进入视野。
- 段落操作和 AI 操作固定在上方；注意事项、术语、前后文和批注放在下方 360 px 的滚动区域。没有注意事项时仍隐藏标题与内容，避免恢复已经移除的矛盾提示。全部参考内容可滚动访问，长内容不再推走操作按钮。
- 检查与修复和检查器共享一个侧栏容器；过渡时按终态宽度布局内容再裁剪，网格同步缩放，结束后恢复自由布局。RTL 镜像方向；用户调整的检查器宽度会在关闭抽屉后恢复。
- 展开即将焦点移到关闭按钮，Esc 可在工作台内收起，立即回到译文编辑框；动画结束不再抢焦点。隐藏、改变窗口尺寸或手动拖分隔条会停止旧动画。
- 移除展开时强制失效的问题清单缓存；数据随任务状态更新。译名修复预览改用当前已加载的只读状态，应用修复仍由核心核对最新 before/after，不放宽一致性检查。
- 列宽变化后的自然行高仍分批计算，单批增加约 4 ms 的时间预算，避免 200 个长段一次堵住事件循环。
- 控件名称复用已有目录，参考滚动区域和检查面板的两句辅助说明追加到 5 个 locale；参考区域可聚焦并用 PageDown 滚动。侧栏完全不透明，没有透明度动画或叠层。
- 收尾修复：参考区明确使用主题背景，深色模式下不再露出浅色原生画布；长参考内容维持自然高度、通过滚动查看，不再把术语按钮压成文字被裁切的窄行。新增深色像素检查和溢出布局回归。

首次展开的额外耗时已通过 cProfile 定位：一部分是重复清空状态签名后扫描整本书；另一部分是 `FollowupPanel.showEvent → preview_entity_repair → load_state`，约 237 ms，其中深拷贝约 220 ms。两条路径都已改掉；没有安装新的采样器依赖。

新增回归覆盖偏好优先级、动画中断与快速输入、减少动画直接到终态、滚动锚定、侧栏固定内容宽度、LTR / RTL、Esc 与焦点、隐藏 / resize、状态缓存刷新、参考内容不推走按钮，以及检查器用户宽度恢复。已有译名应用测试继续验证过期预览会被拒绝。

## 本候选的人工验收

1. 打开一个有长段落与术语的任务，连续切换段落：已在屏幕内的目标行不跳位，上方段落操作和 AI 操作不被参考内容推走；下方可滚动读完参考内容与批注。
2. 点击检查与修复图标，面板展开时立即再点收起；连续快速开合后，终态与最后一次操作一致。点击问题定位段落时，面板保持打开，网格可见。
3. 在检查面板或网格中按 Esc，确认面板关闭并回到译文编辑框；输入文字、按 ⌘↩ 后立即继续输入，确认没有丢失焦点或出现孤立窗口。
4. 在浅色 / 深色主题切换，并查看长参考内容；深色参考区没有白底，术语行没有被竖向压扁，滚动和 PageDown 可以到达下方内容。
5. 在 macOS 系统设置中切换减少动态效果，确认应用读取到新值后尺寸 / 位移动效直接到终态；滚动锚定仍保留。系统偏好读取有最多 5 秒缓存。

这些人工项尚未代签通过；读屏器和真实键盘自动重复速率仍按上文清单验收，不使用 AX 自动化。
