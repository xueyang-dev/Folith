# 反馈 41 施工记录

本轮修改面向 Qt 桌面端。原始反馈 README 和截图保留，施工后的截图见 [implemented/](implemented/)。

## 对应改动

1. **侧栏比例**：导航和最近项目改用 13px 字号；导入按钮使用 14px 字号、48px 高度。
2. **品牌字标**：保留彩色图标，文字按界面语言生成。中文为 Folith · 译页 / 智能体翻译工作台；英语只显示英文；阿拉伯语、俄语、西班牙语采用音译品牌名与意译的「译页」。
3. **通用设置**：外观只保留日间、夜间、跟随系统；高光色单独选择蓝色、翠绿、石板色。移除重复主题预览。旧纸面、翠绿偏好分别映射到日间 + 石板色、日间 + 翠绿。
4. **模型设置**：保存多份连接，支持编辑、删除、模型目录、获取模型和手动添加模型。添加区区分内置提供商和自定义 API；自定义 API 有 Provider ID、名称、地址、协议、密钥和模型目录。翻译、独立审校选择已保存的连接与该连接的模型，视觉用途在视觉页选择。同一 API 可供三个用途使用不同模型，获取的模型目录也会保存。删除正在使用的连接时解除对应用途，不会擅自选择另一个 API。
5. **连接浮窗**：显示实际模型名；沿用翻译连接的用途不重复显示，完全相同的独立连接也合并显示。用量范围选为**当前打开的任务**，其中的估算 token 单独标记；没有账本时不编造用量。浮窗使用透明窗口、自绘圆角和投影。
6. **任务库**：移除概览大条和筛选计数，保留标题下的一行可点击统计；删除「其他任务」。继续任务卡改为横向摘要，较矮窗口隐藏这张重复摘要。1180×780、980×640 下选中任务后，第一排封面仍完整可见。
7. **视觉与识别**：合为一张卡，先选择扫描件的读取方式。VLM 选择已保存连接，本机 OCR 显示语言和安装信息。未检测到 Tesseract 时禁用该选项并提供安装链接。旧任务使用的 Tesseract 后来被卸载时，启动前显示改用视觉理解的提示，并记录任务状态及活动日志；已保存的运行配置也同步使用本次实际来源。恢复安装后可恢复原选择；用户重新选择读取方式时清除旧回退标记。
8. **任务默认值**：增加快速 / 标准 / 精细的默认翻译方式，只预选准备页，不自动开跑。MTI 功能并入可选项。交付格式去掉文件名与重复说明。
9. **关于**：反馈增加 `xydev@outlook.sa`，点击可打开本机邮件客户端。
10. **说明文字**：移除设置卡片中的解释段落，较长字段解释移到提示中；语言选择保留「重启后生效」这一必要信息。

## 连接与密钥

- 连接库和用途选择保存在现有 `provider_config.json`，文件权限仍为 0600；现有翻译 / 审校配置字段继续供引擎使用。旧单连接与旧独立视觉连接在读取时整理为连接条目，下一次明确保存时写入。
- 专用视觉用途仍复用引擎原有的 online-OCR 私密配置文件；不用再填写第二份密钥。
- 自定义 API 当前只提供引擎已支持的 **OpenAI Chat Completions** 协议；内置目录仍保留其原有协议。
- 密钥可留空使用环境认证，例如 `OPENAI_API_KEY`、`DEEPSEEK_API_KEY`、`GEMINI_API_KEY`。环境解析出的翻译 / 审校密钥不回写连接库。独立审校不会借用其他连接的密钥或地址。
- 没有向外部服务上传配置或文档。

- 相关界面、连接迁移、用途保存、封面布局、多语言、交付默认值等回归：**119 项通过**。

- 截图由 Qt offscreen 渲染，使用合成任务与假密钥；包括中文、英文、阿拉伯语 RTL、俄语和西班牙语界面。
