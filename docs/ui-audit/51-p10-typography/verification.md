# P10 全局字体层级（2026-10-15）

分支 `feat/0.6-native-workbench`。实现、自动验证、逐页截图与本地包验证均已完成；人工签收尚未完成。没有 push。

## 层级与范围

依据 [Apple Typography](https://developer.apple.com/cn/design/human-interface-guidelines/typography) 的平台字体、清晰层级和阅读优先原则，保留本产品既有阅读密度，并使用 macOS 的 17 / 22 标题档。Qt 数值为逻辑像素，不把它们误称为 Cocoa 的物理点数，也不声称实现了 Dynamic Type。

| 用途 | 字号 | 字重 / 颜色 | 实际入口 |
|---|---:|---|---|
| 页面标题 | 22（display 展示档 28） | 700 / brand-ink | 任务库、语言资产、项目、欢迎与关于 |
| 区块标题 | 17 | 600 / text-primary | 术语、审校概览、报告、案例、QA、检查侧栏、文件概览 |
| 卡片 / 条目标题 | 15 | 600 / text-primary | 任务卡、模式卡、风格卡、设置分区、审校条目、任务详情 |
| 正文、输入与译文 | 14 | 400 / text-primary | 表单、网格、编辑器，保留阅读字号 |
| 分组标签 | 13 | 600 / text-secondary | 检查器分组、准备分组、交付文件分组 |
| 次要说明 | 12 | 400 / text-secondary | 操作说明、卡片元数据、字段提示 |
| 紧凑元信息 | 11 | 400 / text-muted | 格式、时间、版本等非主要内容 |
| 数字 | 30 / 14 / 12 | 视信息用途沿用主色或次要色 | 大指标 / 行内汇总 / 进度；不把所有数字放大 |

既有 `termsHeading`、`reviewHeadline`、`reviewItemTitle` 和 `role=muted` 此前没有对应 QSS，实际退回默认正文；本次补齐。分组标题从 11px 粗体浅色调整为 13px 中粗体次要色，去掉强制字距以保留阿拉伯语连写。自绘交付列表与按钮宽度测量和普通控件使用同一系统字体及 CJK 回退，避免自绘和 QSS 分叉。所有颜色继续来自主题 token。

未改变布局流程、动效偏好、快捷键与交互语义。新增 P7 调用次数文案已追加到五个 locale；P10 本身没有新增用户文案。

## 自动验证与性能

验证的失败信号：模式设置被覆盖或恢复批次改变；QSS 不再编译 / 主次按钮失效；字体变化使现有准备页、检查器、滚动和窄窗口约束失败；共享逻辑影响 Streamlit。出现这些失败将修复后复验相关项。结果：`scripts/run_regression.py` 一次完整运行 **240 个文件**（239 pytest + 1 脚本），**3719 项 pytest 通过，失败文件 0**，耗时 24 分 12 秒。见 [逐文件结果](regression.tsv) 与 [完整汇总日志](regression.log)。包含 P7 梯度 14 项、任务设置、共享设置 / 恢复及 Streamlit 相关用例；主窗口 84 项、样式 8 项均通过。没有为字体数值编写镜像实现的测试，使用现有布局、交互与回归约束验证实际结果。

最终候选及文档生成后，人工验收包、发行记录、品牌组合复验 **31 项通过、3 项跳过**。跳过原因为项目现有 `local_build.skip_unless_fresh` 规则要求 clean HEAD，而构建带 dirty 标记（保留用户既有 `.claude/`）；不宣称这些静态项通过。随包身份和启动由 DMG 探针直接验证通过，产品源码相对 `28a6ba5` 无差异。构建、DMG、发行说明及候选身份工具均成功。

使用既有 `p1_idle_refresh.py` 对同一 3856 段 / 23.6 MB 原任务的隔离副本复测：旧字体打开 614 ms、未变化刷新前五次 13–14 ms；新字体打开 770 ms、前五次 15–16 ms，第六次启用 cProfile 为 37 ms（旧字体 32 ms）。这是各一次的本机样本，不能将 156 ms 差值全部归因于字体，也不是 P4 严格 16 ms 帧验收。截图生成并行时曾测到打开约 1.23 秒、刷新 27–31 ms，待截图进程结束后才取上述对照值；保留 [performance.json](performance.json) 中的并行负载样本，不把它隐去。

字体层级本身不增加模型调用；P7 的 239 段相同比例复测见 [P7 收尾记录](../50-p7-gradient/verification.md)。
