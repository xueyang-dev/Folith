## 2. 三条硬规则（校验脚本按这三条判）

1. **审校**只指「校对译文」。术语候选的人工关卡一律「确认」，候选状态一律「待确认」。
   `审核` / `审查` / `审定` 不得用于这两件事（`审核` 只在真的表示第三方审计时可用，本仓库目前没有这种界面文案）。
2. **术语**：状态词只允许 `候选 / 暂定 / 已锁定 / 已拒绝 / 待确认`；「冻结」不得用于术语（只属于交付快照）。
   `已确认` 不得用作术语状态（它是人工决定 / 风格规则 / 作者说明的状态）。
3. **交付快照**：`冻结交付 / 已冻结交付 vN` 不动（第 1.3 节）。
