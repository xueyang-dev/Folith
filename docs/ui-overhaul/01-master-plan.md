## 1. 艺术方向（贯穿全程）

现在像「管理得很好的办公室」，要变成「一张书桌」。**保留**：纸页封面（DocThumb/CoverArt）、同明度语义色、三层表面、准备页左图右表、选中段左侧蓝条。

**要做的**是让「纸页」从首页延伸到三个时刻，其余保持安静：

| 时刻 | 界面 | 现在 | 目标 |
| --- | --- | --- | --- |
| 封面 | 首页 | 纸页好看，但文字盖在模糊正文上 | 纸页干净，文字在纸**下**方，像书脊上的一本书 |
| 阅读 | 翻译工作台 | 按表格排文字 | 行距与字体按阅读定，工具退到边上 |
| 装订 | 交付 | 按钮 + 两个空框 | 译好的文档回到画面中央，成为一本做完的书 |

## 3. 阶段与分工

依赖顺序来自原文：**先补证 → 状态一致 → 关键操作可见 → 结构细节 → 书卷气**。

### Wave 0 · 补证（`verifier`，只读生产代码）

* **F1**：离屏量出四种语言的最小宽度，定位到底哪个控件把宽度撑起来（页头？筛选行？）。产出 `docs/ui-overhaul/10-f1-width-evidence.md` + 可复跑的脚本 `scripts/ui_overhaul_measure_widths.py`。
* **F2**：用合成任务（带一条旧式阻断项）复现「四处说法打架」，钉死每处读的是哪个字段（`adapter.py:4323` 收据 vs 旧式项）。产出 `docs/ui-overhaul/11-f2-status-evidence.md`。
* 两个证据文件都要写清：复现命令、期望 vs 实际、修复落点建议、能在 macOS 上做到 / 做不到的边界（Windows 真机、真实任务属于后者）。

### Wave 1 · 状态只说一种话（Lead 主写，`i18n-vocab` 配合）

* **F4 + F2**：新增 `folith/qt/status_voice.py` —— 唯一的状态出口：
  `status_voice(state) -> StatusVoice(label, tone, progress, blocking, anchor)`。
  `views.py`、`projects_view.py`、`theme.py` 全部改为调用它，禁止再各自维护映射表。
  四处界面读同一份 `blocking` 计数；有阻断时页头不出现「已完成」。
* **F16**：一份词表（`docs/ui-overhaul/12-glossary.md`）落到 `i18n` 目录；
  `scripts/check_ui_locales.py` 增加词表校验。

### Wave 2 · 关键操作清楚可见（Lead + `style-tokens`）

* **F7 / F10**（`style-tokens`）：工具按钮 `control-bg` + `border-hairline`；禁用态去填充；
  `text-muted` 提到 4.5:1，必要时与 `text-secondary` 合并。改 `theme_tokens.py` + `style.py`。
* **F1 / F3 / F5**（Lead）：首页页头与筛选行可折行；门禁主位换「去处理 N 个问题」；
  「开始翻译」进页头主按钮位。

### Wave 3 · 结构与细节（Lead + `panel-detail`）

* **F12 / F13**（Lead）：检查器常用动作收敛到 3–4 个，「排除」入更多菜单；面板打开时检查器让位。
* **F14**（`style-tokens`）：阴影内缩对齐问题（`theme.py:84`）。
* **F15 / F17 / F18 / F19-面板部分**（`panel-detail`）：术语表统一、状态圆点、图标语义、模式卡共用、下拉 13px。
* **F19 / F20**（Lead + `i18n-vocab`）：剩余细节 + 规范对齐。

### Wave 4 · 书卷气（Lead + `style-tokens`）

* **F6**（`style-tokens`）：阅读排版倍率（拉丁 1.5 / 中文 1.7）+ 阅读字体设置项（可选，不写死平台字体）。
* **F8 / F9 / F11**（Lead）：封面文字下移、夜间封面压暗、交付页变成「做完的书」。
