# Folith 标准标记

`folith-mark-final.svg` 是 Folith 唯一的标准标记（2026-10-16 修正几何，画布 1254×1254）。
它随包复制为 `folith/resources/brand/folith-mark.svg`，并渲染为 `folith-mark-hires.png`；
页面图标、App 图标和 lockup 都从它派生，见 `docs/brand.md` 的资产矩阵。

修正内容：两页同样大小、沿对角线等距错开，外轮廓中心对称；前后穿插的分界线下移，
浅色页占可见面积 57%；视觉重心居中并上提 1.5%。颜色、渐变、文 / A 和指针不变。

白色层是一条 evenodd 路径，同时包含「文」、「A」和指针；需要分开使用时按 `M` 子路径拆分
（指针是包围盒约 436,416–858,901 的那一条）。

早期的探索稿（印章版、旧几何复刻、对称与旋转变体及其生成脚本）已删除：仓库只保留一个 logo。
