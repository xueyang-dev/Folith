判定只有三种：

- **有证据**：能点开的路径、PR 或 Actions run，并且它满足这一条，不是邻近的另一件事。
- **部分**：有相关记录，但缺这条要求的机器、构建、轮次或原始结果。
- **缺**：没有能点开的记录。

证据文件按计划应放在 `docs/evidence/`，并写上构建号、机器、命令和原始结果。离屏和单元测试不能代替冻结版或真窗口。
