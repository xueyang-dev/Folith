# Folith 0.7.1 发布说明与验收矩阵

状态：2026-10-23 发布候选，尚未创建 v0.7.1 Release。v0.7.0 已于
2026-10-22 发布；之前文档声称它从未发布、0.7.1 已于 22 日发布，均不符合
GitHub 实际记录，本次更正。

## 版本变化

- 长任务空闲轮询避免整表重绘，打开任务先显示加载反馈，再分片填充可见行。
- 知识反馈的模型请求移出串行提交区，journal 按增量记录知识候选。
- journal 恢复保留已经提交的译文，终态保存等待 worker 释放锁；Windows
  文件争用与心跳回归纳入完整 CI。
- PDF 源视图自检实际运行 PDF 任务，并检查渲染和高亮。
- Windows 安装/卸载拒绝覆盖运行中的程序；卸载只删除应用自己的文件。
- 共用姓氏的英文双人姓名缩写不再被误判为多个句末，完整译文可正常导出。
- 低风险批次可跳过独立语义审校，但不计为已审校或可进入 TM；手动全量审校
  先确认段落数和本地估算的 token 下限。
- 名称冲突使用统一选择器；句子切分保留原始空白；DOCX 页眉页脚按契约往返。

详细变更见 [CHANGELOG](../CHANGELOG.md)。

## 支持范围与已知限制

本次原生硬件验收为 Windows 11 x64，build 26200。Windows 10 x64 是构建目标，
尚未在本轮实机验证；Windows ARM64、独立干净 Windows VM、原性能 VM、S3 睡眠
和休眠未验收。未把这些范围计为通过。无需安装 Python、Git 或开发环境。

安装版和便携版均未签名。内置 Tesseract 的 eng/chi_sim/ara 语言包；其他语言
需要自行添加语言包。不随包 PaddleOCR 或 LibreOffice。扫描件可使用在线视觉模型，
需要用户配置相应服务。macOS 包未签名、未公证，本轮 Windows 证据不代替 macOS
人工验收。真实模型翻译质量、独立审校覆盖仍由具体任务的交付检查决定。

## 安装与升级

下载 `Folith-Setup-0.7.1-windows-x64.exe`，关闭正在运行的 Folith 后安装。
升级前建议备份数据目录；安装目录内的用户文件不会被卸载器递归删除。
便携版 `Folith-Qt-0.7.1-windows-x64.zip` 解压后运行 `Folith/Folith.exe`。
用发布页 `SHA256SUMS.txt` 校验下载文件。若提示程序仍在运行，退出后重试，
或取消安装/卸载；不要强行覆盖运行中的目录。
