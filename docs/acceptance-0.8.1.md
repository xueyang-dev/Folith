# Folith 0.8.1 原生验收清单

对应 [发布说明](release-notes-0.8.1.md) 核对表里所有「待人工」的行。自动化（CI、offscreen、mock 平台）不能代替这些检查，也不能代替真实 Cocoa / Windows 窗口。

## 开始前

- **验收对象：** CI 在冻结提交上构建的 macOS arm64 DMG 与 Windows x64 安装包 / 便携版。本机自己构建的 DMG 最低系统版本是构建机的版本，只能做早期试用，不能作为验收结论。
- **先记下身份：** 关于 → 诊断里的版本、build id；下载文件的 SHA-256（`shasum -a 256` / `Get-FileHash`）。填在文末的记录表里。
- **不要污染真实数据：** 验收前设置独立目录再启动，例如 `FOLITH_DESKTOP_DATA_DIR`、`FOLITH_DESKTOP_LOG_DIR`、`FOLITH_QT_SETTINGS_DIR` 指向临时目录。需要用你自己的真实任务时，先备份数据目录。
- **示例材料：** 一本带插图的真实 EPUB、一份 PDF（文字层）、一份扫描 PDF、一份 DOCX。需要模型连接的步骤会产生真实调用，先决定用哪个连接。
- **结果写法：** 通过 / 失败 / 未做；失败要附一句现象、截图或诊断包。「未做」不等于通过。

标记：**【阻断】** 失败则不能发布；**【说明】** 失败也要记录，但可以带着已知限制发布。

|---|---|---|---|---|
| A1 | 安装与首次启动 | 拖进「应用程序」，右键 → 打开；关于 → 诊断 | 能启动；版本是 0.8.1；build id 与记录一致；未签名提示只出现一次 | 阻断 |
| A2 | 界面重做：小窗口 | 窗口缩到约 1280×720，依次看首页、准备页、工作台、审校页、交付页 | 「开始翻译」始终可见；没有横向滚动条；按钮文字不被裁成半截（放不下时是「…」且有悬停提示） | 阻断 |
| A3 | 界面重做：主题与封面 | 日间、夜间各看一遍首页任务卡 | 封面文字在纸页下方、不压在正文上；夜间封面不刺眼；灰色说明文字读得清 | 说明 |
| A4 | 外语界面 | 切到 English、Español、Русский、العربية 各看工作台顶栏与侧栏 | 状态行与主按钮不被裁；阿拉伯语侧栏「项目」角标按 RTL 镜像、不压标签 | 说明 |
| A5 | 交付页：冻结与成果 | 任选一个已译完的任务，冻结交付 | 顶部有版本、文件数、总大小、交付时间；按「译文 / 双语对照 / 术语表」分组；技术附件默认折叠 | 阻断 |
| A6 | 交付页：文件操作 | 点「下载全部（ZIP）」「打开文件夹」「另存交付文件…」；对单个文件试打开、在访达中显示、复制路径 | ZIP 内容与冻结清单一致；文件夹是真实交付目录；另存时同名文件有覆盖确认 | 阻断 |
| A7 | 交付页：缺文件 | 冻结后在访达里删掉快照目录里的一个文件，回到交付页再点「下载全部」 | 拒绝打包并说出是哪个文件；不产生半套 ZIP | 阻断 |

| A9 | 智能 QA 开关 | 打开顶部「自动处理有确定依据的问题（实验）」；展开「自动处理（审计）」看证据；撤销一条；关开关；重开任务 | 有确定依据的发现进审计组；撤销后回到队列；关开关后所有发现回到人工队列；重开任务后选择仍在 | 阻断 |
| A10 | 批量统一译名 | 在含 ≥2 条译名冲突的任务里点「批量统一译名」 | 对话框弹出；展开一行有逐段改前改后；取消后译文不变；确认后选中项写入译文；开关开启与关闭时按钮都可见 | 阻断 |
| A11 | 术语卡 | 展开概念决策类术语卡 | 显示锁定译法、旧译法、受影响段数；没有值时不出现空字段 | 说明 |
| A12 | EPUB 插图 | 用带插图的真实 EPUB 走完整流程，交付译文 EPUB 与 DOCX | 图片出现在对应段落之后、图注之前；图片数量与原书一致；无法转换的图片列在导出报告里 | 阻断 |
| A13 | 暂停后换连接 | 翻译中暂停 → 改模型或 Key → 继续 | 继续立即用新连接；运行头显示实际在用的「服务商 · 模型」；已识别的页面与译文保留 | 说明 |
| A14 | 扫描页与成本 | 导入扫描 PDF 翻译，看任务页「成本」 | 显示调用次数与 token；不显示金额；失败页的记录注明所用连接 | 说明 |
| A15 | 撤销 | 在译文框用辅助功能或输入法整段上屏后按 ⌘Z | 整段被撤销，不只是最后一个字 | 说明 |
| A16 | 真实中文输入法 | 在译文框用真实中文输入法打字、选词、回车 | 候选窗位置正确；上屏正常；保存不丢字 | 阻断 |
| A17 | AX 崩溃修复 | 用 Accessibility Inspector 或 VoiceOver 读取界面，同时打开一个任务（重复 5 次） | 不崩溃。可选对照：以 `FOLITH_QT_AX_WORKAROUND=0` 启动，记录是否复现 | 阻断 |
| A18 | 长文档交付 | 分别对 PDF、DOCX、EPUB 各走一遍：导入 → 翻译 → 审校 → 冻结 → 另存 | 全程不崩溃、不卡死；交付文件能被对应软件打开 | 阻断 |
| A19 | 旧任务升级与中断恢复 | 用 0.8.0 创建的任务打开；翻译中强制退出后重新打开并继续 | 旧任务能打开且数据不丢；中断后能从检查点继续 | 阻断 |
| A20 | 退出与睡眠 | 点 Dock 退出（有任务运行时有确认）；电脑睡眠唤醒后任务状态 | 退出提示正确；唤醒后不丢任务 | 说明 |

## 结论怎么判

- 所有**【阻断】**项为「通过」，且 CI 在冻结提交上全绿、至少两次连续全绿：可以进入打 tag。
- 有阻断项失败：记录后修复，修复后只重做相关项和 C2。
- **【说明】**项失败：写进发布说明的已知限制，不阻止发布。
- 该清单只覆盖 0.8.1 的改动范围；0.8.0 已有的其余人工项（真实模型服务、干净机器等）仍按 [0.8.0 的验收矩阵](qt-beta/acceptance-matrix.md) 执行。
