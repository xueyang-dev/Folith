# G1-S 加压驱动的 3 轮冒烟

这不是 30 轮门槛，也不是 Windows 验收。只证明 `scripts/frozen_stress_rounds.py` 能在现成的 macOS 冻结包上跑完，并写出每轮记录和汇总。30 轮要等最终候选和用户时段。

脚本提交是 `c82cbd0c`。冒烟用的就是这一版，证据文档在它之后补上。

## 环境

| 项 | 值 |
| --- | --- |
| 机器 | 本机 arm64，macOS 27.0.1（Build 26A434） |
| Python | 3.11.3（仓库 venv） |
| 冻结包 | `.loop/builds/0.8.2-baseline-8109b9c2/dist/Folith.app`，已有的基线包，这次没有重新构建 |
| 轮数 | 3 |

命令（在 `wb/0.8.2-g1-stress` 工作树里）：

```text
python scripts/frozen_stress_rounds.py --rounds 3 --frozen-app .loop/builds/0.8.2-baseline-8109b9c2/dist/Folith.app --out <临时目录>
```

冻结包参数实际传的是这份已有的 `.app`。输出目录在临时盘，不进仓库：里面的 OCR 报告含本机路径。

## 原始结果

脚本结束时打印：

```text
{"rounds": 3, "abnormal_exit_count": 0, "system_crash_record_count": 0, "crash_query_supported": true}
```

进程退出码 0。

`rounds.jsonl` 三行（只留轮次、退出码、耗时、用例是否通过）：

| round | exit_code | duration_s | 四个用例 ok |
| --- | --- | --- | --- |
| 1 | 0 | 69.112 | pdf_scanned、pdf_chinese_scanned、pdf_arabic_scanned、missing_pack 都是 true |
| 2 | 0 | 68.429 | 同上 |
| 3 | 0 | 68.443 | 同上 |

`summary.json`：`abnormal_exit_count` 0，`system_crash_record_count` 0，`system_crash_records` 空，`crash_query_error` 空，`platform` darwin，`executable` Folith。macOS 查的是 DiagnosticReports 里文件名含 Folith 的新报告。开跑前已有的报告没有算进来。

## 单元测试不算这次冒烟

`python -m pytest -q tests/frozen_stress_rounds_test.py`：`8 passed in 0.11s`。

这里面 Windows 的 `Get-WinEvent` 分支是用假的 PowerShell 输出测的，**没有在 Windows 上执行**。macOS 分支的文件名过滤也是用临时目录测的。这两个都只算单元测试。上面的 3 轮才是一次真的冻结包运行，而且只覆盖了 macOS。
