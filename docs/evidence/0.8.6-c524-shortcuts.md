# 0.8.6 C5（#524）第 1 块：审校快捷键单一来源 + 共享键帽

日期：2026-11-21。分支 `feat/0.8.6-c524-shortcuts`，基线 `origin/main` `265bd623`（#523 合入）。

## 改动

1. `folith/qt/platform_ui.py::_CUSTOM` 增加 6 个审校动作：`review_next/apply/open/confirm/keep/edit`，
   绑定 N/A/O/C/K/E 与 `shortcut_text()` 的 `NativeText` 显示同源（macOS 显示 ⌘/⌥，
   Windows 显示 Ctrl/Alt 时亦自动适配，无 OS 分支）。
2. `folith/qt/components.py` 新增共享 `KeyHint(action)`：只接受 platform_ui 动作名，
   用 `shortcut_text(action)` 渲染，复用既有 `QLabel#keyHint` QSS（与搜索框 ⌘K 同款）。
3. `folith/qt/review_panel.py`：QShortcut 全部由 `platform_ui.shortcut(action)` 构造；
   底部手写句子换成 6 个 `KeyHint`，辅助描述也从同一定义生成（不再有字面 A/O/C…）。
4. `folith/qt/settings_pages.py::LOCAL_SHORTCUTS` 列出 6 个审校动作。
5. 7 locale 追加 12 条标签；`qt_i18n_coverage.py` 1942/1942 缺 0。
