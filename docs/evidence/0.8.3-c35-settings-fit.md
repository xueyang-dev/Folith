# 0.8.3 C-35 PR-1：设置窗口与对话框统一不超屏 + 底栏一行

日期：2026-11-21。分支 `fix/0.8.3-c35-settings-fit`，基线 `origin/main` `265bd623`。
对应用户亲测 U-1 / U-6 / U-7（`.loop/reports/user-findings-0.8.3.md`）。

## 改动

1. 新模块 `folith/qt/dialog_fit.py`：统一用 `QScreen.availableGeometry()`（跨平台，无 OS 分支）
   算出能装下整窗（含装饰）的客户区上限，`fit_to_screen()` 夹进可用区、必要时相对父窗口居中；
   `FittedDialog` 在 `showEvent` 首次居中、之后保持顶边。`MARGIN=12`。
2. `EngineDialog`：所有页共用 `_clamp_to_screen`/`_fit_height`；`_fit_height` 不再用
   85%/820 猜测，改为 `max_client_height()` 的真实可用高度，超出时页面自己的
   `QScrollArea` 滚动、标题与底栏固定。
3. `ConnectionLibrary._build_editor` 的「添加/编辑连接」对话框改用 `FittedDialog`，小屏下不再超屏、居中。
4. **底栏一行**：状态文字与「测试并保存」同一行（状态在左、按钮在右），与内容区之间一条
   发丝线；`QWidget#settingsFooter` 用 `bg-surface` 同色，不再把窗口截成两半。
5. `folith/qt/style.py` 新增 `#settingsFooter` 一条 token QSS。
