# 0.8.3 C2（#520）剩余块：toast 堆叠与提示边缘安全

日期：2026-11-20。分支 `feat/0.8.3-c520-notices2`，基线 `origin/main` `d77a990d`。
第 1 块（语气/图标/底部定位 + `NoticeBanner` 组件）已由 #538 合入；本 PR 收尾两块。

## 改动

1. **Toast 堆叠**（`folith/qt/notifications.py` 新增 `ToastStack`）：最多 3 条，最新在最上方、旧的往下叠；删除最旧的临时通知（success/info/progress），错误与警告常驻不被挤掉。悬停暂停全部计时。`ToastStack` 是普通对象（非 QWidget），几何/显隐方法显式转发给最新一条；测试断言 `main.toast.y()` 等于最新 toast 的 y；`window.py` 只改一行导入与构造（5,224 行不变）。
2. **提示边缘安全**（新模块 `folith/qt/notice_placement.py`）：纯函数 `place_within()` 把小浮层先限制在所属窗口、再限制在屏幕；下方放不下就翻到锚点上方，窄窗口下也不会越出左边界。`clipped()` 供测试与诊断使用。未改 `Popover` 的原生行为或任何平台专属代码。
3. 未做（保持第 1 块边界）：`WorkbenchView.set_task_notice` 的行内横幅接入需要 `views.py` 布局改动，按规则 views.py 只能入口级改动；本次不改。全部 `_notice` 文案规则也留待后续。
