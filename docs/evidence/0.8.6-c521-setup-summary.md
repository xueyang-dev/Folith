## 改动

- 新模块 `folith/qt/delivery_summary.py` 的 `DeliverySummaryRow`：包图标 + 方案名 +
  文件统计 + 可选 chevron，`set_summary(preset, detail)` 同时更新 tooltip / accessible name；
  样式只用主题 token（`bg-surface` / `border-hairline` / `rowTitle` / `rowValue`）。
- `folith/qt/setup_panel.py`：折叠区「交付内容」的 body 里加共用摘要行；原散落的
  `delivery_summary` 小字隐藏（事实只说一遍）；`_sync_delivery_summary()` 同时更新
  方案名（从 `delivery_seg.value()` 取标签）与文件统计。
- `folith/qt/delivery_panel.py`：`_Header` 也放一条同名组件，刷新时填入冻结版本 + 文件数。
- `folith/qt/style.py`：新增 `#deliverySummaryRow` QSS 一条（token，无硬编码颜色）。
- 7 个 locale 追加 1 条 `交付内容：{v0} · {v1}`。
