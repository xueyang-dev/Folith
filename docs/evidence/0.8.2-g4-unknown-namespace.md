口径（用户 2026-11-15 认可，代替计划里的「一律拒绝」）：

- 规范允许的扩展点上，外来元素原样保留、不编辑、不拒绝。规范依据：XLIFF 1.2 扩展点。真实文件 `test1_es.xlf` 的外来元素在 `<trans-unit>` 里，不在行内，所以仍是 140 个单元、`rejections` 为空。

**没有在 Trados 或 memoQ 里打开过这些文件。**

工作台是否可见、能否编辑，以及 1,000 单元真窗口，仍等 P3-5。这两条不在下面的「通过」里。
