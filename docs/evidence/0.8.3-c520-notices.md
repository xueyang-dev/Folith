# 0.8.3 C2（#520）第 1 个 PR：小通知的语气与共享组件

日期：2026-11-19。分支 `feat/0.8.3-c520-notices`，基线 `origin/main` `19618f3b`。
机器：macOS arm64，Qt 6.11.2 / PySide6 6.11.2，offscreen。

## 本次范围（#520 拆分的第 1 块）

- `folith/qt/notifications.py`：主题化的 `Toast` 与新增 `NoticeBanner`。
  - 五种语气 `success / info / warning / error / progress`，各自有主题图标引擎的图标；
    颜色只走 `theme.STATUS_TONES` 的语义 token（`done / active / attention / error`）。
  - Toast 固定在窗口底部中央；success/info/progress 约 5 s 后淡出，error/warning 常驻，
    悬停暂停淡出；「详情」仍打开非模态全文。
  - 长名字用 `QFontMetrics.elidedText(…, ElideMiddle, …)` 中间省略，完整文字留在
    tooltip、accessible name 与详情里——不重写用户文件名或路径（AGENTS.md）。
  - `NoticeBanner` 是一行：图标 + 省略语句 + 可选动作 + 关闭；同一套语气与 token。
- `folith/qt/style.py`：为两种卡片新增 `QFrame#noticeToast` / `#noticeBanner` 的
  `bg-surface` + `border-hairline` + 圆角规则；没有硬编码颜色。
- 7 个 `qt-*.json` 只追加一条 `关闭提示`。

## 尚未包含（后续同 issue 的 PR）

行内任务横幅接入 `WorkbenchView.set_task_notice`、toast 堆叠（最多 3 条）、
首次提示的边缘翻转与箭头、全部 `_notice` 调用点的文案规则。当前 PR 不动
`window.py` / `views.py`，因此行数上限不受影响；`_notice` 的现有路由不变。
