# 0.8.6 C3（#523）审校页头：模式开关 + 统计标签

日期：2026-11-20。分支 `feat/0.8.6-c523-review-header`，基线 `origin/main` `eba19231`。

## 问题与改动

1. **统计标签被挤成 0 宽**（`style.StatStrip`）：`ElideLabel` 的 sizePolicy 是 Ignored（最小宽 0），
   布局末尾又有 `addStretch(1)`，四个标签被压到 0 宽、只剩数字。现在给每个名称一个正数
   `minimumWidth`，每个 cell 用 stretch 1，去掉末尾 stretch；真放不下仍由 ElideLabel 省略。
   `StatStrip` 是共享组件，首页等其他使用者同样受益。
2. **自动处理不像模式开关**：新模块 `folith/qt/triage_mode.py` 的 `TriageModeRow` 把
   `components.Switch` + 可见状态（「自动处理（实验）：开/关」）+ 常驻说明
   （「只对本任务生效 · 每条可撤销 · 不改译文」）+ 一行反馈放在同一处；反馈区分
   「已自动处理 N 条」/ N=0 的原因 / 关闭后记录仍在审计组可撤销。
   `review_panel.py` 用它替换裸 `QCheckBox`，对外仍暴露同一个 `toggled` 信号与
   `isChecked/setChecked` 接口；行为、存储、交付门禁不变，window.py 零改动。
