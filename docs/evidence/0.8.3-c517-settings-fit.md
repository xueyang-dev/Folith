# 0.8.3 C1 · #517 设置窗口适配 / 固定操作 / 模型页简化

日期：2026-11-19。分支：`feat/0.8.3-c517-settings-fit`，基线 `origin/main` `4c253adc`。
机器：macOS arm64，Qt 6.11.2 / PySide6 6.11.2，offscreen 后端（`QT_QPA_PLATFORM=offscreen`）。

## 改动

1. **适配并居中**（`folith/qt/dialogs.py`）：新增 `EngineDialog._clamp_to_screen()`，用
   `QScreen.availableGeometry()`（跨平台，排除 macOS Dock/菜单栏与 Windows 任务栏）
   夹住含标题栏的 `frameGeometry()`，并相对主窗口居中（主窗口不在可用区内时退回
   可用区居中）。`_fit_height()` 的每次高度变化（含动画每一帧）后和 `showEvent()`
   首次显示时都重新夹一次；首次布局完成后经 `QTimer.singleShot(0)` 再量一次内容
   高度，避免构造期拿到旧 `sizeHint` 把窗口定矮。
2. **操作固定**：「测试并保存」从连接页的滚动内容里移到对话框的固定区
   `self._pinned_actions`，只在「模型」页显示；页内容滚动时按钮不动。
3. **模型页简化**（`folith/qt/connection_library.py`）：连接改为单行（圆点 · 名称 ·
   提供商 · 默认模型 · 模型数 · 状态 · ⋯）；编辑/删除收进「⋯」菜单；超过 4 条折叠，
   显示「显示全部 (N)」，点开后滚回列表顶部。两个新字符串补进全部 7 个 `qt-*.json`。

## 局限

offscreen 截图测不到 macOS 真 Cocoa 标题栏、Dock 实际遮挡和 Windows 任务栏 / 100%、
125%、150% 缩放下的原生窗口。这三类需要监工派 W 在 Windows 真机补验；本机只按
`availableGeometry()` 的跨平台语义做了几何断言。
