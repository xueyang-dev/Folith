# 0.8.3 C1c · #547 切换界面语言时提示重启

日期：2026-11-19。分支 `feat/0.8.3-c547-language-restart`，基线 `616a0d84`。
机器：macOS arm64，offscreen，PySide6 6.11.2。

## 实现

- 新模块 `folith/desktop/relaunch.py`：模块级 pending 标记 + 三条启动分支
  - macOS 冻结版：`open -n <bundle> --args …`（按 `sys.executable` 向上找 `.app`）
  - Windows 冻结版：`subprocess.Popen([sys.executable, …], CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS)`
  - 源码运行：`sys.executable + 原脚本 + 原参数`
  - 不在桌面模块之外放平台分支，不碰 Sparkle 更新路径。
- `folith/qt/app.py`：`app.exec()` 返回后才调 `relaunch.after_exit()`；此时旧窗口已在
  `closeEvent` 的 `_release_instance()` 里释放单实例锁，新进程不会撞锁。
- `folith/qt/dialogs.py`：
  - 语言选择不同于已保存值时用主窗口的 `_confirm` 弹框（标题「需要重启 Folith」、
    主按钮「立即重启」、取消「取消」）；有任务在运行时补一句会停止任务并可继续。
  - 取消：下拉框退回原值、偏好不变、退出流程不启动。
  - 接受：先 `_apply_preferences()` 保存，置 relaunch pending，再 `parent.close()` 走与
    正常退出完全相同的流程。0 ms + 500 ms 轮询观察 `_exit_in_progress`：退出被取消 /
    失败（窗口仍在且退出已结束）时清掉 pending 并提示「语言已保存，下次启动时生效」。
  - 删掉静态「重启后生效」小字，改为下拉框悬停提示。
- `window.py` 零改动（5,224 行不变）。
- 6 条新文案追加到全部 7 个 `qt-*.json`（按插入序，只追加）。
