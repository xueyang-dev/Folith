冻结包里没有命令行入口做 XLIFF 导入/导出（`--help` 只有 `--smoke` / `--selftest` /
`--selftest-fixture` / `--ocr-report` / `--diagnostics-report` 等），这一项在 GUI 里是人工点击操作，
本轮没有做。

自动化层面的覆盖（本机实跑，不是冻结包）：
