# 0.8.3 C-40：目录 reveal 与沿用服务默认标注

日期：2026-11-21。基线 `origin/main` `97c6777a`。一个小 PR，0.8.3 范围。

## 改动

1. 新模块 `folith/qt/reveal_path.py::reveal_path_or_directory()`：路径是目录时调
   `file_actions.open_directory()`，否则仍调 `reveal_in_file_manager()`。不改 `file_actions.py`
   对文件的语义；`window.py::reveal_path` 单行替换调用（行数仍 5,224）。
2. `connection_library.update_level_selector`：沿用行无单独值时，`effective_level()` 为空则按
   `service_default` 处理，因此被选中的那一项总带「（沿用翻译）」。

## 测试与变异检查

`tests/qt_c40_final_test.py` 3 passed：目录→open_directory、文件→reveal；翻译空→审校/视觉
「服务默认（沿用翻译）」；翻译 Off→「Off（沿用翻译）」，单独改后不带标注。
两处变异检查分别让对应用例变红。`line_budget_test.py` 6 passed，四文件行数未增；ruff 0 new。
