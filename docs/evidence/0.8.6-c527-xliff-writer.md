# 0.8.6 C8（#527）第 1 块：任意任务的 XLIFF 1.2 生成器

日期：2026-11-21。分支 `feat/0.8.6-c527-xliff-writer`，基线 `origin/main` `89c52e57`。

## 改动

新模块 `folith/xliff_writer.py`（纯函数，不写文件、不写任务状态）：
- `build_xliff(job)` 输出完整 XLIFF 1.2 文档：每个 segment 一个 `trans-unit`，
  `id` 取稳定 segment uid（老任务回退 `seg-NNNN`），`source-language`/`target-language`
  与 `original`/`datatype` 来自任务；
- 状态映射写入代码常量表：untranslated→`new`、机器译文→`translated`、
  人工确认→`signed-off` + `approved="yes"`、有开放 finding→`needs-review-translation`；
- 排除段不静默丢弃：发 `translate="no"` + `<note>excluded: not translated</note>`；
- XML 特殊字符用 `sax.saxutils.escape` 转义。
