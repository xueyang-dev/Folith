## 逐条

**SDLXLIFF：`QuotesSample.docx.sdlxliff`（5 段，2 个子段锁定）**

- 导入后 `state["xliff"]["dialect"] == "sdlxliff"`，5 段全部 `readonly`（方言只读）。
- 工作台第 1 行显示文件里的译文（`Che verrà. ...`），编辑框只读，状态行写「已锁定（只读）」，保存与「重译」不可点。
- 交付面板只有「原样导出双语文件…」，没有「导出双语文件并写入译文…」。
- 桌面顶部没有「继续翻译」「重试」——双语任务不进翻译管线。
- 导出字节与原文件**逐字节相同**（断言 `output.read_bytes() == original`）。
- 截图：`assets-0.8.2-g5-ui/g5-sdlxliff-workbench.png`、`assets-0.8.2-g5-ui/g5-sdlxliff-delivery.png`。

**MQXLIFF：`locked.mqxliff`（3 段，单元级锁定）**

- 方言判为 `mqxliff`，3 段全部只读；交付面板同样只有「原样导出双语文件…」。
- 导出字节与原文件逐字节相同。
- 截图：`assets-0.8.2-g5-ui/g5-mqxliff-workbench.png`、`assets-0.8.2-g5-ui/g5-mqxliff-delivery.png`。

**通用 XLIFF 1.2：`validators.en.xlf`（P3-6 界面导出抽查）**

- 从界面把第 1 段的译文改成 `This value should be false. [p3-6]`，再用交付面板的「导出双语文件并写入译文…」导出。
- 界面导出的字节与 `core.export_xliff_task(..., write_targets=True)` 的字节**完全相同**——界面没有第二套写入器。
- 对导出的文件跑 OASIS strict 与 transitional：与源文件相比**没有新增**校验错误。strict 上源文件已有的错误仍在，与内核证据一致。
- 改写的那一段在导出文件里是新译文，其余单元与源文件一致。
