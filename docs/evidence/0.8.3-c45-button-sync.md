# 0.8.3 C-45：模型页底栏按钮随连接增删即时同步

日期：2026-11-22。基线 `origin/main` `c7b5ab4e`。

## 改动

- `EngineDialog.sync_models_primary_button()` 一个函数负责底栏主按钮的文字与唯一槽位：
  有连接→「测试并保存」→`apply_connection`；无连接→「添加连接」→`open_editor`。
  每次都先 `disconnect` 再连接，切页不会叠加槽。
- `show_page()` 调该函数；`ConnectionLibrary.refresh()`（被保存/删除/刷新调用）也调它，
  因此新增连接后不切页按钮立即更新，删除最后一条后立即回退。
- `_focus_missing_field()` 改为按字段对象（provider/model/key/base/add）判断，
  不再靠「密钥」「key」等文案匹配，西/俄/阿/法/德都适用。
