# G-E 第 5 项：冻结版「开始 → 首批译文」延迟（macOS）

- 日期：2026-11-19
- 被测产物：Release Validation run [`44479114452`](https://github.com/xueyang-dev/Folith/actions/runs/44479114452) 的 `folith-qt-macos` artifact
  - `Folith-Qt-0.8.2-macos-arm64.dmg`
  - `build/qt-desktop/desktop_build_info.json`：`commit = ee99abd5baa4aa353267db8bd5939c5ba171860a`、`built_at = 2026-11-19T07:42:54+00:00`、`app_version = 0.8.2`（0.8.3 尚未提版本号）
- 机器：本机 macOS arm64，`QT_QPA_PLATFORM=offscreen`；冻结包拷到 `/tmp/ge-frozen/Folith.app` 运行（不跑 DMG 原位）
- 网关：仓库自带确定性网关 `scripts/d0_fake_llm_server.py`（零延迟），不看真实模型速度
- 测量工具：`tests/engine_first_batch_latency_test.py`（`FOLITH_FROZEN_APP` 指向冻结版可执行文件）

## 口径

起点 = 向 `Folith --engine-host` 发出启动请求；终点 = **第一批译文落盘且界面可见**：`runtime_state`
出现第一条 `state_commit_done`（「已保存第 1 批译文」），或 `state.json` 的 `pairs` 非空，谁先到算谁。

不含 journal：干净跑完的批次会在快照包含它们之后被 compaction 退休，`state_journal.jsonl` 随即消失，
不能作为终点（第一次跑就踩到了这一点，测到"180 s 无首批译文"而任务其实 1 秒内就完成了）。

含：子进程 `import core` 冷启动（E-1 实测冻结版约 1.2 s）+ 第一次模型往返。

## 结果（n=5，单位秒）

| 轮次 | 1 | 2 | 3 | 4 | 5 | **中位** | 门限 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 开始 → 首批译文 | 1.234 | 1.049 | 1.034 | 1.067 | 1.037 | **1.049** | ≤ 3.0 |

**结论：门槛 GE 第 6 条的后半（冻结版首批译文中位 ≤ 3 s）在 macOS 上满足**，实测中位
**1.049 s**，最差一轮 1.234 s。前半条（Start 后 1 s 内出现启动状态）由
`folith/desktop/engine_supervisor.publish_starting_status`（#534，`ee99abd5`）覆盖：
它在发出启动行**之前**同步写 `queued/starting`，并有测试钉住顺序。
