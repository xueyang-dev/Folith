# G-E 第 6 项：冻结版 `FOLITH_ENGINE_PROCESS=1` 的主流程冒烟（macOS）

- 日期：2026-11-19
- 产物：RV run [`44479114452`](https://github.com/xueyang-dev/Folith/actions/runs/44479114452) 的 `folith-qt-macos`
  - `build/qt-desktop/desktop_build_info.json`：`commit = ee99abd5baa4aa353267db8bd5939c5ba171860a`
  - 冻结包拷到 `/tmp/ge-frozen/Folith.app` 运行（不跑 DMG 原位）
- 驱动：`scripts/qt_desktop_probe.py --frozen-app … --fixture txt --window --screenshot …`
- 模式：**`FOLITH_ENGINE_PROCESS=1`**（引擎在独立子进程里跑流水线）

## 结果

`report.json`：**`ok: true`、`exit_code: 0`**，11 步全部走过（原文顺序）：

```text
imported → opened → translated → draft-saved → edit-submitted →
reviewed → delivered → saved → screenshot → exit → reopened
```

- `job_ids`：1 个任务；`exit` 之后 `reopened` 成功，说明退出后任务还在、可继续。
- **子进程模式确实生效**（不是"设了开关但还跑进程内"）：该任务的 `runtime_events.jsonl` 里有
  ```text
  run_launched   | 已启动新的运行
  engine_starting | 正在启动后台引擎进程
  ```
  第一条由 `core.register_engine_owner(launch=True)` 在**启动子进程之后、发送启动行之前**写入，
  第二条由 `#534` 的 `publish_starting_status` 写；两条都只在子进程路径出现。
- **退出后无残留进程**：`pgrep -fl /tmp/ge-frozen` 为空（GUI 与引擎子进程都退干净）。

## 限制

- 只覆盖 macOS 冻结版这一端；Windows 真机同项由 W 用 `folith-qt-windows` 做。
- 这是**冒烟**：主流程 + 退出 + 重开。生命周期矩阵的两模式覆盖由测试
  `tests/qt_lifecycle_probe_modes_test.py`（#536）负责；首批译文延迟见
  `docs/evidence/0.8.3-ge-first-batch.md`。
- 冻结包版本仍显示 0.8.2（0.8.3 尚未提版本号），按提交号 `ee99abd5` 定位产物。
