# 0.8.3 尾巴：禁用下拉的灰色样式（C-23）

日期：2026-11-20。分支 `chore/0.8.3-combo-disabled-style`，基线 `origin/main` `73a42792`（#562 合入）。

## 问题

#562 里目录不认识的模型，其「思考强度」列 `setEnabled(False)` 后看起来和可用的一样
（黑字、同样边框），用户看不出点不了。规格第 3.2 节要求灰字「服务默认」。

## 改动

`folith/qt/style.py` 的 QSS 补 `QComboBox:disabled`（透明底 + `disabled-ink` 灰字 +
`border-faint` 极淡轮廓），并显式让 `:disabled:hover` / `:disabled:focus` 不覆盖该边框。
两条 token 都是主题已有的，亮/暗自动生效；无硬编码颜色、无新字符串、无 locale 改动。
