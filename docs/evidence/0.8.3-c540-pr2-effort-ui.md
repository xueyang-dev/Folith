# 0.8.3 C1b（#540）PR-2：按用途的思考强度、迁移与编辑器收口

日期：2026-11-19。分支 `feat/0.8.3-c540-effort-ui`，基线 `origin/main` `944eeee1`。
机器：macOS arm64，offscreen。测量窗口期间（C-17）本机只跑秒级单文件测试与读写代码/文档。

## 改动

### 1. 用途区三列（新模块 `folith/engine/effort_settings.py`）

`folith/qt/connection_library.py` 的翻译 / 审校 / 视觉三行各加一个「思考强度」下拉：
- 选项**只**来自 PR-1 的目录（`effort_settings.choices`），永远含「服务默认」；
- 未在目录里的模型只有「服务默认」，不可选；
- Local Gateway 等无 Off 档的模型提供 Low/Medium/High，悬停说明「这个模型无法关闭思考」；
- 审校 / 视觉未显式选时沿用翻译行的档位，仍可单独改（视觉常需更低档）；
- 旧值不在目录里时显示「旧设置：…」并**原值照发**，只有用户主动改才替换。`to_job_fields()`
  把档位转成现有 job config 认识的两个标量（`reasoning_effort` / `reasoning_mode`），运行时路径不变。

### 2. 连接编辑器去掉两行

`reasoning_row`（推理强度）与 `thinking_row`（思考）不再放进连接编辑面板；连接只管地址、
密钥、模型清单。控件对象保留但不再显示，避免破坏既有数据兼容。

### 3. 迁移（不悄悄改变行为）

`EngineConfig` 新增 `connection_levels`（只加字段、不删旧字段，可降级回 0.8.2）；
`core.save_provider_config` / `load_provider_config` 与 `EngineConfig.load/save` 透传该字典。
`effort_settings.migrate()` 把旧的 `reasoning_effort` 与连接上的 `reasoning_mode` 转成按用途
的档位；幂等；旧值不在新目录时保留原值照发。任务创建时翻译用途的档位写进 job 的
`reasoning_effort`（`folith/qt/adapter.py` 的映射处）。

### 4. locale

7 个 `qt-*.json` 只追加 4 条新文案（档位标签模板、旧设置前缀、两条悬停说明）。
