## 改动

- `folith/qt/settings_pages.py::StoragePage`
  - 数据位置与清理路径改用共享 `style.ElideLabel`：长路径中间省略，完整路径保留在 tooltip
    与可复制文本里；
  - 「占用空间」各行初始文案由裸 `…` 改为「计算中…」（新文案进 7 个 locale）；空目录经
    `storage_view()` 得到 0，显示 `0 B`；
  - 「在Finder中显示」的模板改为 `在 {v0} 中显示`，`v0` 仍来自
    `platform_ui.file_manager_name()`（macOS「Finder」/ Windows「资源管理器」），中英文都有空格。
- locale 只追加：`计算中…`、`在 {v0} 中显示`。
